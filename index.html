卷一 · 自叙

关于此间

少好格物，长而笃志于算学机巧。尝诵先贤之典，通组成、网络、数据结构之要义，明操作系统之枢机，每有会意，便欣然忘食。

及至弱冠，负笈泰岳，修计算机之术。于课业之余，尤好探大模型之幽微。观今之智械，虽能言善辩，然于算法逻辑，常有疏漏，或生"幻觉"，或陷悖谬。余乃以科班之基，设难考辨，纠其偏颇，累计正谬误十五余处，使稀疏图之准度，自七二升至八九，此诚践行"知行合一"之乐也。

亦曾构健身房管理系统，以 SpringBoot 为骨，Vue 为衣，化繁为简，行数字化之便。又常游刃于 Python、Linux、Git 之间，善写 Prompt 以导推理，长于清洗比对以净语料，心性细密，不惮烦琐。

余之所趣，不在浮名。蓝桥一奖，偶得之耳；CET 之证，亦为览西文技术文档之阶。平日好读博弈论与认知之书，喜探物理硬件底层之奥，以为万物皆有理，理在毫末间。又嗜长跑、骑行，盖取"绵绵若存，用之不勤"之意，于往复中炼专注，于长途里守恒常。

今既栖身于智识之林，愿效前贤格物致知，以逻辑为尺，以数据为鉴，助大模型去伪存真，还算法以清明。此间乐，不足为外人道也。

—— 是为自述

卷三 · 雅趣

技术之外的天地

代码之外，亦有诗书茶画，风月闲情

终日与逻辑为伴，亦不忘向山水问心。
键盘之外，有墨痕、有茶烟、有书卷气。
此卷所录，皆闲时之趣，不足为外人道，然自得其乐。

书

养气

诗书养气，最是静心

少时读《古文观止》，最爱《赤壁赋》中"惟江上之清风，与山间之明月"一句，觉天地辽阔，物我两忘。及长，涉猎渐广，从《诗经》的草木虫鱼，到唐宋诗词的四季流转，再到明清小品的闲适清言，每有会意，便觉千年文脉不过咫尺。

类别 书目 偶得
古典文学 《古文观止》《世说新语》《诗经》 读《世说》，知魏晋风流

思想 《道德经》《庄子》《传习录》 "无用之用"，创造力的源头
杂览 博尔赫斯、卡尔维诺、建筑美学 在异域文字里，寻另一种时空

墨

栖心

东方美学，是另一种逻辑

近日
· 临《兰亭序》第二十七遍（每次都有新悟）
· 计划探访苏州拙政园（体味"移步换景"的空间叙事）

书法初学颜真卿，后慕赵孟頫之秀逸。临帖时，一笔一画，心神俱静，恍若与古人隔空对谈。虽未成气候，然笔墨之间，自有法度与自由并存的妙趣。

绘画偏爱文人山水，尤喜倪瓒"逸笔草草，不求形似"的境界。园林则取法苏州，一峰则太华千仞，一勺则江湖万里，以小见大的智慧，何尝不是架构设计的真谛？

思

问道

技术的尽头，往往是哲学

写代码时，会想起老子的"凿户牖以为室，当其无，有室之用"——软件的架构，亦是在"有"与"无"之间寻找平衡。

读康德时，会联想起图灵测试：什么是"物自体"？机器能有"先验综合判断"吗？这些问题或许无解，但追问的过程本身，就是思维的拓展。

常常缠绕我的问题

当大模型生成一首"像李白"的诗，它是在模仿，还是在"创作"？

技术是中性的，但技术人的选择呢？

快时代里，如何保持"慢思考"的能力？

每一次叩问，都让代码多一层人文的底色。

创

游艺

将古人的智慧，译作今日的界面

做个人网站时，试着把"新中式"的审美转化为可交互的体验：用留白代替边框，让呼吸感成为设计语言；用宣纸色作为背景，替代冰冷的纯白；用楷体与宋体的搭配，模拟古籍排版的节奏。页面滚动如手卷徐徐展开，一轴一轴，渐次呈现。

诗词意象 → UI 动效 宋代版刻 → CSS 排版 AI 中式插画
